# Risks and blockers

| id | risk | impact | mitigation | state |
| --- | --- | --- | --- | --- |
| R1 | Docker is not installed on the build host. | `docker compose up` couldn't be verified locally. | Use rootless Podman 4.9.3 with podman-compose 1.6.0, already installed. `podman build` built the image (27 s) and `podman-compose config` accepts `compose.yaml`. `podman compose up` is verified once lanes A and H land. | resolved (Podman) |
| R2 | Live models are free tiers only (owner decision): Gemini API free tier (default) and OpenRouter `:free` (20 requests/min, 1,000/day on this key). Free models report $0 and can return 429/503 under load. | Live p95 is noisy; "< $0.02/ticket" is met trivially. A Gemini key on a billed project would charge. | Settings and adapters reject non-free model ids. The Gemini key's project is on the free plan (owner confirmed in AI Studio, 2026-11-19). 429/503 are retryable; recording is throttled and resumable, after A, C, and D land. The report states provider, models, and mode. | accepted |
| R3 | GitHub refused branch protection and rulesets on the free-plan private repo (HTTP 403). | Required PRs, required checks, and linear history weren't enforced by GitHub. | Resolved 2026-11-20: the owner moved to GitHub Pro and the repository is public. A ruleset on `main` now requires a pull request, the five CI checks (lint, typecheck, test, evals-smoke, secrets), linear history, and squash merges, and blocks force-pushes and deletion. | resolved |
| R4 | The `mcp` SDK is 2.x (newer than many examples). | Lane A API surprises. | Lane A reads the installed package's source before coding. | open |
| R5 | Free-tier latency: in development run full5 (OpenRouter `:free` Nemotron, 120 s budget), successful model calls averaged 5.5 per ticket, with a per-call p95 of 17.5 s, and the agent's own (non-model) time was 48 ms p50 and 924 ms p95. full3 (30 s budget) timed out 34 of 54 tickets. | The development runs missed the p95 < 8 s target. | The final report is scored from the labeled runs' measured results. If p95 misses, the report says so, with the breakdown and what would close the gap. A second labeled run uses a 120 s budget. No metric is redefined. | accepted |
| R6 | The OpenRouter free tier allows about 1,000 requests a day on this key (R2). | The two labeled runs may not both fit in one day's quota, leaving little room to rerun. | 2026-11-20: a 30 s run on `b67de70`, a 120 s run on `74a3b11`, and spot checks on `d395c1d` and `9b05b11` fit in one day. 2026-11-21: a 120 s rerun on `2c650e6` completed on the next day's quota. Both the 120 s (`2c650e6`) and 30 s (`b67de70`) runs are published in [docs/results.md](../results.md). | open |
